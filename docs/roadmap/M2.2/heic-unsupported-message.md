# heic-unsupported-message

Tag: feature
Milestone: M2.2
Title: HEIC/HEIF photos get a clear "not supported yet, convert to JPEG" message

## Scope

- [x] Detection, pure and in `src/photo/` (e.g. `heic.ts`): `isHeicByName(name)` (`.heic`/`.heif`, case-insensitive), `isHeicMime(type)` (`image/heic`, `image/heif`, `-sequence` variants), `isHeicSignature(bytes)` (ISO-BMFF `ftyp` at offset 4 with major or compatible brand in `heic heix hevc hevx heim heis mif1 msf1`). Unit + fast-check tests (random bytes never false-positive without `ftyp`+brand)
- [x] Type check in `partitionImportFiles` (`src/photo/pickPhotos.ts:92-110`): a HEIC by MIME or extension (including empty / `application/octet-stream` MIME, `:99`) is rejected with the HEIC message instead of `Unsupported image format: …` (`:105`). Reuse the image-like helper that `folder-skip-non-images` adds there, so a HEIC in a folder import stays an error (never silently skipped)
- [x] Magic bytes for the cases a name/MIME check misses: (a) rejected files with empty/octet-stream MIME and no extension get one `file.slice(0, 32).arrayBuffer()` sniff in `importPhotoFilesInner` before errors are built (`src/editor/importPhotos.ts:59-63`; only those files, async, capped like the batch); (b) a worker decode failure whose buffer has a HEIC signature returns the HEIC message instead of the generic decode error (`src/photo/processPhoto.ts:193-196`; buffer already read at `:124`)
- [x] Message (one constant, kit copy): "HEIC isn't supported yet. Export it as JPEG (on iPhone: Settings › Camera › Formats › Most Compatible) and try again." Shown as a per-file entry in the existing `import-errors` list (`src/editor/EditorShell.tsx:378-389`). The file adds no tile and is not counted (rejected before enqueue; for case (b), `failed-import-no-tile` removes the tile)
- [x] Make HEIC pickable so the user gets the message instead of an invisible file: input `accept` adds `.heic,.heif,image/heic,image/heif` (`src/photo/mime.ts:7-9`), and the FSA picker types add a HEIC entry (`pickPhotos.ts:3-12`). `isAcceptedPhotoMime` (`mime.ts:1-5`) still rejects HEIC
- [x] Spec delta `photo-card` "Accepted and rejected image types" (`openspec/specs/photo-card/spec.md:23-35`): HEIC/HEIF rejected with an actionable conversion message, detected by extension, MIME or signature
- [x] Tests: unit (`pickPhotos.test.ts`: `.heic` with `''`, octet-stream and `image/heif` MIME; `processPhoto.test.ts`: decode failure + HEIC bytes → HEIC message, non-HEIC → original error). e2e (`e2e/filmstrip.spec.ts`): a generated minimal `ftyp heic` file as `sample.heic` (and an extension-less copy with octet-stream MIME) shows the HEIC message, `data-gallery-count` unchanged, no tile
- **Done when:** (1) the e2e regression test above fails on main (`Unsupported image format: image/heif` / `application/octet-stream` or a decode error) and passes on the branch; (2) unit/property tests above pass; (3) the spec delta is archived; (4) patch coverage ≥ 85%, Stryker diff ≥ 85 with zero NoCoverage, and no gate weakened or newly excluded; (5) no new dependency and no decoder (DEFERRED.md unchanged)
- **Perf:** name/MIME checks are sync; the 32-byte sniff runs only for unknown-type rejects and never for accepted files. The bulk-import frame-budget scenario stays green and the import kickoff stays inside the `import-photos` handler budget.
- **Browser check:** on the preview URL, Add photos shows `.heic` files in the default filter; picking an iPhone HEIC (with or without extension) shows the HEIC-specific message with the conversion hint, adds no tile and does not change the count; a folder with JPEGs + a HEIC imports the JPEGs and lists only the HEIC message.
- **UI kit:** `uikit/src/features/m0m1.tsx:56-68` and `:238-246` (`m0-photo-card`, `UI ref: uikit#/feature/m0-photo-card` — unsupported HEIC error card + “Open unsupported HEIC” scenario), `uikit/src/features/m25.tsx:128` (`editor-chrome-states` Import error toast lists `scan_0042.heic`, `UI ref: uikit#/feature/editor-chrome-states`), `uikit/src/components/uui/FeaturedIcon.tsx`, `uikit/src/components/ui/button.tsx`. partial: iPhone Settings › Camera › Formats conversion copy (kit says “Export it as JPEG from Photos”)
- **Size:** ~150–250 changed lines (detector + partition/worker wiring + accept lists + spec delta + tests)
