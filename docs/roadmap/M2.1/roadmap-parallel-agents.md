# roadmap-parallel-agents

Tag: prep
Milestone: M2.1
Title: roadmap CLI and agent pipeline support several agents in parallel git worktrees

## Scope

Why: the owner wants up to 5 cursor-agent sessions working M2.1 items at the same time, each in its own git worktree (`~/repos/photobooks-wt<k>`). Today the pipeline assumes one agent in the main checkout: `roadmap next` returns only the first open item (no deps, no explicit slug); `agent preflight` runs `git switch main` + `git pull --ff-only` (fails in a linked worktree because `main` is checked out elsewhere) and claims slugs only from open PRs / remote `feat|fix/*` branches; the push-failure counter writes `<root>/.git/...` (breaks in a worktree where `.git` is a file); `roadmap done` ticks `[x]` on the shared index line on the item branch, so parallel PRs conflict on adjacent lines; `done` on the last open item archives the milestone, and `roadmap check` fails "fully done but still active" when two PRs close the last two items; agents append to `docs/lessons.md` (append-conflicts); `git-finish.mdc` says to stop on a conflict with `main` instead of resolving it.

- [ ] `roadmap next --slug <s>` (validates: exists, open, in an active milestone, not contingency unless asked; prints the same view as `next`) and `roadmap next --skip` keeps working. Optional `roadmap claim <s>` / claimed-set helper used by preflight. Unknown or done slug fails with a clear message
- [ ] `pnpm agent preflight --slug <s>`: works in the main checkout AND in a linked worktree. It fetches and branches `feat|fix/<slug>` from `origin/main` (`git switch -c <branch> --no-track origin/main`, or reuses an existing local branch that is already based on it) without switching or pulling local `main`; clean-tree check stays. Without `--slug` the old behaviour stays (main checkout only)
- [ ] Claimed set = open PR heads + remote `feat|fix/*` + local branches + branches checked out in any worktree (`git worktree list --porcelain`), so `roadmap next` without `--slug` never returns an item another session already holds
- [ ] Every git-internal path uses `git rev-parse --git-dir` / `--git-path` (push-failure counter and anything else under `.git/`), never `<root>/.git`; unit test with a real linked worktree (tmp repo)
- [ ] `.cursor/commands/next-roadmap-item.md` accepts an optional slug argument (`/next-roadmap-item <slug>`) and passes it to preflight; without it the flow is unchanged
- [ ] Done state no longer lives on the shared index line edited by every item PR: e.g. the item PR records done in its own item file (status line) and the index tick is derived/applied after merge (`roadmap check` accepts "item file done, index not yet ticked" for merged items, or `roadmap sync` ticks it), so two parallel item PRs touch no common line in `docs/roadmap.md`. `roadmap list/next/check` read the new source of truth; migration keeps existing done items done
- [ ] Milestone archiving is a separate post-merge step (`roadmap archive <M>` run when every item is done on `main`), not a side effect of `roadmap done`; `roadmap check` tolerates "fully done but still active" until that step (warn, not fail) so the last two items can be closed by parallel PRs
- [ ] `docs/lessons.md` appends: replace with a per-entry file (e.g. `docs/lessons/<date>-<slug>.md`) or another conflict-free scheme, and update the rules that tell agents to append
- [ ] `git-finish.mdc` / command: on a conflict with `main`, `git fetch origin && git merge origin/main`, resolve trivial conflicts (roadmap index/doc lines, lockfile via `pnpm install`, independent hunks), run `pnpm verify:fast:quiet`, push (never rebase or force-push); stop and report only for real semantic conflicts
- [ ] Local e2e/preview port configurable per worktree (env var, e.g. `E2E_PORT`, default 4173) in the Playwright config and preview/test scripts, and no reuse of a server started by another worktree, so parallel agents never test another worktree's build
- [ ] Tests for every changed script path (`scripts/roadmap.mjs`, `scripts/agent.mjs` and helpers are in coverage and mutation scope): `--slug` validation, worktree preflight (tmp repo with a linked worktree and `main` checked out elsewhere), claimed-set from local/worktree branches, git-dir paths, done-state and archive step, check tolerance

- **Done when:** in a tmp repo with `main` checked out in the primary worktree, `pnpm agent preflight --slug <s>` in a linked worktree creates `feat/<s>` from `origin/main` and reports item `<s>`; `roadmap next` skips an item whose branch exists only locally in another worktree; two branches that each mark a different item done merge into `main` without a conflict in `docs/roadmap.md`; closing the last two items in parallel keeps `roadmap check` green until `roadmap archive`; script diff mutation ≥ 85 with no NoCoverage.
- **Size:** ~1000 changed lines (max 1500 incl. tests, initial scope)
- **Source:** owner decision 2026-10-18 11:35 (parallel slots, max 5); Reviewer audit of scripts/roadmap.mjs, scripts/agent.mjs, git-finish.mdc
