# Site fresh A: the stack, read by scrolling

- **Idea:** the books lie in one real pile, and scrolling down the page takes them off it one at a time and reads them.
- **Signature gesture (scroll):** in each book's chapter the scroll turns the closed book from three-quarter to face-on, opens the board cover and turns the first leaves; on the book page the scroll turns every page, front to back cover. Nothing moves unless you scroll; ← / → and a click scroll one page.
- **1440, first screen:** name + Books / About / Contact; on the left a sticky contents list (title, year) that later marks the current book; on the right the lead line and the pile of all books at true size (spines with titles, the top cover seen from above).
- **390, first screen:** name + Menu, lead line, the pile at full width, then the contents as 44 px rows; the chapters stack below as full-screen scenes.
- **1 book:** the home is that book's page (no pile, no list). **12 books:** the pile gets taller and the contents list is grouped by year; each chapter opens the book only to its first spread.
- **References (from memory, no browsing in this session):** Apple product pages (an object turned by the scroll, no hijack);
  Locomotive (native scroll, sticky scenes); Loose Joints and Nadav Kander (the book as a lit object, one quiet type size).
